# 🍕 Zomato Analytics Dashboard

## 📌 Project Overview

This project is an Excel-based Zomato Sales Analytics Dashboard designed to analyze food ordering trends, customer behavior, restaurant performance, and revenue insights.

The dashboard transforms raw order data into meaningful business insights through interactive visualizations and KPI tracking.

---

## 🎯 Objective

To analyze Zomato order data and answer key business questions such as:

- Which cities generate the highest revenue?
- What are the most popular cuisines?
- Which customer segments place the most orders?
- How does revenue vary by month and weekday?
- What are the year-over-year growth trends?
